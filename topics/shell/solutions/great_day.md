### Задание

[Условие](../great_day.md).

<a id="solution"></a>
### Решение

[Исполняемый пример](scripts/great_day.sh) — единственный источник кода; именно его запускают автоматические тесты.

Без аргументов выводит `Today is a great day!`. С одним аргументом выводит `Today is ` и его содержимое. Пустая строка считается переданным аргументом; лишние аргументы — ошибка.

Запуск из корня репозитория:

```bash
bash topics/shell/solutions/scripts/great_day.sh "a sunny day"
```

Ошибки входных данных выводятся в stderr с кодом 2. Нужны Bash 4.4+ и GNU/Linux; общие требования описаны в [разделе Bash](../README.md).
