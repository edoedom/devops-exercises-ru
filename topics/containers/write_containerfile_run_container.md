# Написание Containerfile и запуск контейнера

<a id="objectives"></a>
## Задание

1. Создайте образ:
   * Используйте centos или ubuntu как базовый образ.
   * Установите веб-сервер Apache.
   * Разверните любое веб-приложение.
   * Добавьте поддержку HTTPS через обратный прокси HAProxy.
2. После написания Containerfile и сборки образа запустите контейнер и проверьте приложение. Опишите способ проверки и приведите вывод команд.
3. Назовите один или несколько недостатков своего Containerfile. Готов ли он для использования в рабочей среде?
