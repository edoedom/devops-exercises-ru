## AWS EC2: роли IAM

<a id="requirements"></a>
### Требования

1. Работающий экземпляр EC2 без роли IAM. Предполагается, что на нём не настроены другие учётные данные и вызовы AWS API пока не проходят авторизацию.
2. Роль IAM с политикой IAMReadOnlyAccess.

<a id="objectives"></a>
### Задание

1. Назначьте экземпляру EC2 роль с политикой IAMReadOnlyAccess. Если такой роли нет, создайте её.
2. Проверьте, что на экземпляре можно выполнять разрешённые этой политикой команды AWS.
