## AWS: создание роли

<a id="objectives"></a>
### Задание

Создайте роль, предоставляющую сервису EC2 полный доступ к IAM.<br>
Затем выполните команду в CLI или CloudShell, чтобы проверить создание роли.

<a id="solution"></a>
### Решение

1. В консоли AWS откройте IAM.
2. В левом меню выберите **Access Management → Roles**.
3. Нажмите **Create role**.
4. Выберите тип доверенного субъекта **AWS service**, а в качестве сценария использования — **EC2**. Нажмите **Next**.
5. На странице разрешений выберите IAMFullAccess. Нажимайте **Next** до страницы **Review**.
6. Задайте имя роли, например IAMFullAcessEC2, добавьте краткое описание и нажмите **Create role**.
7. Команда `aws iam list-roles` покажет все роли учётной записи, включая созданную.
