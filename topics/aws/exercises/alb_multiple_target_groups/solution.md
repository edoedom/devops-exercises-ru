## AWS ELB: несколько целевых групп ALB

<a id="requirements"></a>
### Требования

Два экземпляра EC2 с веб-приложением, показывающим строку "Hey, it's a me, `<HOSTNAME>`!".

Ещё один экземпляр EC2 с веб-приложением, показывающим строку "Hey, it's only a test..." по пути /test.

<a id="objectives"></a>
### Задание

1. Создайте Application Load Balancer для первых двух экземпляров:
   1. Порог успешных проверок: 3.
   2. Порог неуспешных проверок: 3.
   3. Интервал: 10 секунд.
2. Создайте вторую целевую группу для третьего экземпляра.
   1. Настройте направление трафика в эту группу по пути /test.

<a id="solution"></a>
### Решение

<a id="console"></a>
#### Консоль

1. Откройте EC2.
2. Выберите **Load balancing → Load balancers**.
3. Нажмите **Create load balancer**.
4. Выберите **Application Load Balancer**.
5. Укажите имя балансировщика.
6. Выберите зоны доступности.
7. Выберите группу безопасности.
8. В разделе **Listeners and routing** нажмите **Create target group**, затем **Instances**:
   1. Укажите имя целевой группы.
   2. Порог успешных проверок: 3.
   3. Порог неуспешных проверок: 3.
   4. Интервал: 10 секунд.
   5. Нажмите **Next** и выберите два из трёх экземпляров.
   6. Нажмите **Create target group**.
9. Обновите список и выберите созданную группу.
10. Нажмите **Create load balancer** и дождитесь завершения создания.
11. В левом меню выберите **Load Balancing → Target Groups**.
12. Нажмите **Create target group**.
13. Задайте те же параметры, но включите в новую группу третий экземпляр.
14. Вернитесь к ALB. В разделе **Listeners** откройте **Edit rules** для текущего обработчика подключений:
   1. Добавьте правило: запросы с путём /test направляются во вторую группу.
   2. Нажмите **Save**.
15. Проверьте результат в браузере, добавив /test к адресу балансировщика.
