## Проверка аргумента

<a id="objectives"></a>
### Задание

[Условие](../argument_check.md).

<a id="solution"></a>
### Решение

[Исполняемый пример](scripts/argument_check.sh) — единственный источник кода; именно его запускают автоматические тесты.

Принимает ровно один аргумент. Сравнивает его с `pizza` как строку, с учётом регистра. Пустая строка допустима; отсутствие аргумента и лишние аргументы — ошибка.

Запуск из корня репозитория:

```bash
bash topics/shell/solutions/scripts/argument_check.sh pizza
```

Ошибки входных данных выводятся в stderr с кодом 2. Нужны Bash 4.4+ и GNU/Linux; общие требования описаны в [разделе Bash](../README.md).
