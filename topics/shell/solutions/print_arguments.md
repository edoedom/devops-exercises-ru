## Вывод аргументов

<a id="objectives"></a>
### Задание

[Условие](../print_arguments.md).

<a id="solution"></a>
### Решение

[Исполняемый пример](scripts/print_arguments.sh) — единственный источник кода; именно его запускают автоматические тесты.

Выводит первый аргумент с меткой `First:`, количество с меткой `Count:`, затем каждый аргумент с меткой `Arg:`. `"$@"` сохраняет границы аргументов, включая пустые строки, пробелы и литеральную `*`. Без аргументов поле First пустое, Count равен 0.

Запуск из корня репозитория:

```bash
bash topics/shell/solutions/scripts/print_arguments.sh "two words" "" "*"
```

Ошибки входных данных выводятся в stderr с кодом 2. Нужны Bash 4.4+ и GNU/Linux; общие требования описаны в [разделе Bash](../README.md).
