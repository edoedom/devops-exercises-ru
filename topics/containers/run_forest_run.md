## Беги, Форрест, беги!

<a id="objective"></a>
### Цель

Разобраться в политиках перезапуска контейнеров и научиться ими пользоваться.

<a id="requirements"></a>
### Требования

Убедитесь, что Docker установлен и служба запущена.

```
# Fedora/RHEL/CentOS
rpm -qa | grep docker
systemctl status docker
```

<a id="instructions"></a>
### Инструкции

1. Запустите контейнер:
   * Образ: alpine.
   * Имя: forest.
   * Политика перезапуска: always.
   * Команда: sleep 15.
2. Выполните `docker container ls`. Работает ли контейнер? А через 15 секунд? Почему?
3. Как остановить этот контейнер?
4. Удалите его.
5. Запустите такой же контейнер с командой `sleep 600` и убедитесь, что он работает.
6. Перезапустите службу Docker. Работает ли контейнер? Почему?
7. Измените политику на `unless-stopped`.
8. Остановите контейнер.
9. Перезапустите службу Docker. Работает ли контейнер теперь? Почему?
