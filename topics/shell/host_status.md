## Проверка доступности узла

<a id="objectives"></a>
### Задание

1. Напишите скрипт, который определяет, доступен ли указанный узел.

Уточните контракт: один ICMP echo-запрос через Linux iputils ping. Различайте полученный ответ (код 0), отсутствие ответа (1), ошибку проверки (2). Отсутствие ICMP-ответа не означает недоступность всех служб узла. Для автоматических тестов подмените ping заглушкой, не обращайтесь к сети.
