## AWS Route 53: создание записей

<a id="requirements"></a>
### Требования

Хотя бы один зарегистрированный домен.

<a id="objectives"></a>
### Задание

1. Создайте запись для своего домена:
   1. Имя записи: foo.
   2. Тип: A.
   3. В поле значения укажите IP-адрес.
2. Из командной оболочки проверьте, что созданная запись позволяет получить IP-адрес по доменному имени.

<a id="solution"></a>
### Решение

1. Откройте **Route 53 → Hosted zones**.
2. Нажмите имя своего домена.
3. Нажмите **Create record**.
4. Введите foo в поле **Record name**.
5. Выберите тип A в **Record type**.
6. В поле **Value** введите 201.7.20.22.
7. Нажмите **Create records**.
8. В оболочке выполните `nslookup foo.<YOUR DOMAIN>` или `dig foo.<YOUR NAME`.

> Примечание к переводу: в исходном примере команды dig пропущен закрывающий символ `>` у обозначения подстановки. В обеих командах нужно подставить реальное имя домена; сами обозначения в угловых скобках вводить не нужно.
