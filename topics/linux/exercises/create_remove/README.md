<a id="objectives"></a>
## Задание

1. Создайте файл `x`.
2. Создайте каталог `content`.
3. Переместите файл `x` в каталог `content`.
4. Создайте в каталоге `content` файл `y`.
5. Создайте внутри `content` структуру каталогов `dir1/dir2/dir3`.
6. Удалите каталог content.
