## Пустые файлы

<a id="objectives"></a>
### Задание

1. Напишите скрипт, который удаляет все пустые файлы в указанном каталоге, включая вложенные каталоги.

По умолчанию выводите список без удаления; удаляйте только с явным флагом `--apply`. Включите скрытые файлы, не обходите символические ссылки и не удаляйте каталоги. Отклоняйте `/`. Проверяйте решение на собственном временном каталоге без конкурентных изменений.
