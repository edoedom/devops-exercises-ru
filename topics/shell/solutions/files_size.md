## Место на диске

<a id="objectives"></a>
### Задание

[Условие](../files_size.md).

<a id="solution"></a>
### Решение

[Исполняемый пример](scripts/files_size.sh) — единственный источник кода; именно его запускают автоматические тесты.

Без аргументов обходит элементы текущего каталога, включая скрытые. Для каждого выводит занятое место в байтах по `du --summarize --block-size=1`, табуляцию и экранированное имя. Для каталога учитывается его дерево. Это выделенные блоки, а не логическая длина файла; hard links при отдельных вызовах du могут учитываться повторно. Цели символических ссылок не обходятся. Пустой каталог не даёт строк результата.

Запуск из корня репозитория:

```bash
bash topics/shell/solutions/scripts/files_size.sh
```

Ошибки входных данных выводятся в stderr с кодом 2. Нужны Bash 4.4+ и GNU/Linux; общие требования описаны в [разделе Bash](../README.md).
