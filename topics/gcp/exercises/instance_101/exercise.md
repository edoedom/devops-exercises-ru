# Создание экземпляра

<a id="objectives"></a>
## Задание

1. Создайте виртуальную машину со следующими параметрами:
   1. Имя: instance-1.
   2. Тип: e2-micro.
   3. Метки:
      1. app: web.
      2. env: dev.
2. С помощью CLI gcloud:
   1. Измените значение метки app на db.
   2. Удалите метку env.
