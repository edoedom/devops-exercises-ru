## Текущая дата

<a id="objectives"></a>
### Задание

1. Напишите скрипт, который записывает текущую дату в файл `the_date.txt`.

Формат даты — `YYYY-MM-DD`, часовой пояс — локальный. Файл перезаписывается, строка заканчивается переводом строки. Скрипт не принимает аргументов.
