## Текущая дата

<a id="objectives"></a>
### Задание

[Условие](../basic_date.md).

<a id="solution"></a>
### Решение

[Исполняемый пример](scripts/basic_date.sh) — единственный источник кода; именно его запускают автоматические тесты.

Без аргументов записывает локальную дату в формате `YYYY-MM-DD` и перевод строки в `the_date.txt`. Используется `date +%F`; повторный запуск перезаписывает файл.

Запуск из корня репозитория:

```bash
bash topics/shell/solutions/scripts/basic_date.sh
```

Ошибки входных данных выводятся в stderr с кодом 2. Нужны Bash 4.4+ и GNU/Linux; общие требования описаны в [разделе Bash](../README.md).
