## Git: объединение коммитов

<a id="objective"></a>
### Цель

Научиться объединять несколько коммитов в один (squash).

<a id="instructions"></a>
### Инструкции

1. Создайте новый учебный репозиторий без коммитов (Git 2.28+), настройте локальные имя и email автора. Создайте файл с содержимым Mario и зафиксируйте его в коммите.
2. Измените содержимое файла на Mario & Luigi и создайте ещё один коммит.
3. Убедитесь, что существуют два отдельных коммита.
4. Убедитесь в чистом рабочем дереве и объедините оба коммита в один через `git rebase -i --root`.
5. Проверьте, что остался один коммит, итоговое содержимое и ID дерева сохранились. Не публикуйте промежуточную историю.

<a id="after-you-complete-the-exercise"></a>
### После выполнения задания

Ответьте на вопросы:

* Для чего объединяют коммиты?
* Можно ли объединить более двух коммитов?
