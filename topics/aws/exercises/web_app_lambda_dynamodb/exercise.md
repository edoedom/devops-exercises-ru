# HTTP API с Lambda и DynamoDB

## Задание

Создайте учебный API без собственного сервера: клиент → API Gateway HTTP API → Lambda → DynamoDB.

1. Таблица `users` с partition key `id` типа String, режим оплаты по запросам.
2. `PUT /users/{id}` принимает JSON с непустым строковым `login` длиной до 100 символов и сохраняет запись; `GET /users/{id}` возвращает её либо 404.
3. Lambda получает имя таблицы из `TABLE_NAME`, а временные AWS credentials — из execution role.
4. Роль разрешает только необходимые GetItem/PutItem конкретной таблицы и запись журналов; у Lambda нет постоянных ключей AWS в коде.
5. Для API включите IAM-авторизацию. Проверяйте его подписанными SigV4-запросами; обычный curl без подписи должен получить отказ.
6. Верните 400 для неверного JSON и login, 200 для успешной операции; не возвращайте клиенту трассировки ошибок AWS.
7. Проверьте создание, чтение и отсутствие записи. После упражнения удалите созданные ресурсы.

AWS может начислять плату. Используйте отдельное учебное окружение и настройте бюджет. В каталоге `terraform/` находится полная учебная конфигурация и обработчик. Выполните init/validate/plan, проверьте расходы и только затем apply в отдельном аккаунте.
