# Проверка внешних ссылок

Дата: 5 ноября 2026 года. Из 286 исходных Markdown-файлов извлечены 488 уникальных URL-кандидатов. Проверялись HTTP-ответы и перенаправления; это не проверка содержания каждой страницы, всех anchors или прав на изображения.

После повторов 467 кандидатов вернули HTTP 200, один — 301. Шесть адресов являются учебными или локальными примерами и исключены из результата: обращаться к кластерным именам или подставлять реальные частные адреса для этой проверки не требуется. Две ложные ошибки извлечения URL Википедии с круглыми скобками исправлены при повторе, исходные ссылки в материалах были правильными.

## Исправления

| Старый адрес или материал | Результат |
|---|---|
| Статья Christian Posta об API gateways в старом блоге | Ссылка заменена публикацией автора на Solo.io |
| Avi Networks Layer 7 как источник определения HTTP | Ссылка заменена RFC 9110 |

| Статья WhiteSource о supply chain, ответ 403 | Используется спецификация SLSA и обновлённое объяснение |

Новые страницы Grafana и Defender ответили 200. RFC и новая публикация Solo.io проверены через доступный веб-источник. Три Perldoc-адреса (`perlobj`, `IPC::Open3`, `functions/eval`) дали тайм-аут в прямой проверке, но успешно прочитаны через веб-источник; ссылки сохранены.

## Неоднозначные результаты

- `https://selinuxproject.org/` вернул 503: это сбой сервера, а не доказательство удаления проекта. Ссылка сохранена.
- Профили авторства `https://twitter.com/ks_nenasheva` и `https://www.flaticon.com/authors/freepik` дали 404 в повторном запросе. Имена авторов и исходная атрибуция в credits.md сохранены; новый профиль не подставлялся без подтверждения личности и авторства.
- HTTP 200 не гарантирует актуальность содержимого. Редиректы, авторизация и защита от автоматических клиентов могут влиять на результат.

Автоматическая проверка отклонила повторный сетевой обход, содержащий внутреннее учебное имя `some.kubernetes.cluster.svc`. Продолжение было ограничено явным списком публичных сайтов документации без автоматического следования перенаправлениям; доступ к внутренним сервисам не проверялся.
