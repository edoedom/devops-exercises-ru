## Пустые файлы

<a id="objectives"></a>
### Задание

[Условие](../empty_files.md).

<a id="solution"></a>
### Решение

[Исполняемый пример](scripts/empty_files.sh) — единственный источник кода; именно его запускают автоматические тесты.

Принимает каталог и по умолчанию только показывает пустые обычные файлы. Для удаления нужен первый аргумент `--apply`. Обход рекурсивный, включая скрытые файлы; символические ссылки не обходятся, каталоги не удаляются. Вывод экранируется через `printf %q`, поэтому имя с переводом строки остаётся одной строкой отчёта. Корень `/` отклоняется. Используйте собственный учебный каталог, который другие процессы не меняют во время обхода: этот пример не решает гонки при конкурентной замене файлов.

Запуск из корня репозитория:

```bash
bash topics/shell/solutions/scripts/empty_files.sh ./sandbox
```

Ошибки входных данных выводятся в stderr с кодом 2. Нужны Bash 4.4+ и GNU/Linux; общие требования описаны в [разделе Bash](../README.md).
