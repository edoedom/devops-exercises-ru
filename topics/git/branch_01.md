## Git: ветки 01

<a id="objective"></a>
### Цель

Научиться работать с ветками Git.

<a id="instructions"></a>
### Инструкции

1. Создайте отдельный учебный репозиторий с веткой `main` и одним коммитом (Git 2.28+). Настройте имя и email автора локально.
2. Создайте ветку `dev` и переключитесь на неё.
3. Измените один из файлов репозитория.
4. Создайте коммит.
5. Сравните `main..dev` и `dev..main`: новый коммит должен быть достижим из `dev`, но не из `main`. Проверьте версии файла в обеих ветках.
