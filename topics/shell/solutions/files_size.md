## Размеры файлов

<a id="objectives"></a>
### Задание

1. Выведите имя и размер каждого файла и каталога в текущем каталоге.

Примечание: используйте хотя бы один цикл `for`.

<a id="solution"></a>
### Решение

> Примечание к переводу: Исходный пример разбирает вывод `ls`, поэтому имена с пробелами и переводами строк обрабатываются некорректно. `du -sh` показывает объём занятого места, а не обязательно логический размер файла. Код оригинала сохранён.

```
#!/usr/bin/env bash

for i in $(ls -S1); do
    echo $i: $(du -sh "$i" | cut -f1)
done 
```
