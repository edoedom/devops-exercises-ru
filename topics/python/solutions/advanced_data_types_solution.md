## Определение типов данных: повышенная сложность

Для каждого примера определите тип значения полученной переменной.

1. a = {'a', 'b', 'c'} -> set (множество)
2. b = {'1': '2'} -> dict (словарь)
3. c = ([1, 2, 3]) -> list (список)
4. d = (1, 2, 3) -> tuple (кортеж)
5. e = True+True -> int (целое число)
