## Подсчёт символов

<a id="objectives"></a>
### Задание

1. Считывайте ввод пользователя до получения пустой строки.
2. Для каждой введённой строки подсчитайте количество символов и выведите результат.

<a id="constraints"></a>
### Ограничения

1. Используйте цикл `while`.
2. Предполагается, что пользователь введёт не менее трёх строк.

<a id="solution"></a>
### Решение

> Примечание к переводу: Исходное решение завершает цикл при конце ввода, а не при пустой строке. Кроме того, `wc -c` считает байты, поэтому для многобайтовых символов результат не равен количеству символов. Код оригинала сохранён; эти расхождения нужно учитывать при проверке решения.

```
#!/usr/bin/env bash

echo -n "Please insert your input: "

while read line; do
    echo -n "$line" | wc -c
    echo -n "Please insert your input: "
done
```
