## ICMP-проверка узла

<a id="objectives"></a>
### Задание

[Условие](../host_status.md).

<a id="solution"></a>
### Решение

[Исполняемый пример](scripts/host_status.sh) — единственный источник кода; именно его запускают автоматические тесты.

Принимает один IP-адрес или ASCII-имя узла. Выполняет один `ping` с ограниченным ожиданием ответа (Linux iputils). Код 0 — получен ICMP-ответ; 1 — ответа нет; 2 — некорректный ввод, отсутствующий ping или ошибка проверки. Отсутствие ответа не доказывает, что узел выключен: ICMP может фильтроваться. Проверка не измеряет доступность HTTP/SSH и не отправляет почту. Тесты подменяют ping локальной заглушкой, без сетевых запросов.

Запуск из корня репозитория:

```bash
bash topics/shell/solutions/scripts/host_status.sh 127.0.0.1
```

Ошибки входных данных выводятся в stderr с кодом 2. Нужны Bash 4.4+ и GNU/Linux; общие требования описаны в [разделе Bash](../README.md).
