## AWS ELB: балансировщик Application Load Balancer

<a id="requirements"></a>
### Требования

Два экземпляра EC2 с простым веб-приложением, которое показывает строку "Hey, it's a me, `<HOSTNAME>`!".

<a id="objectives"></a>
### Задание

1. Создайте Application Load Balancer для этих экземпляров:
   1. Порог успешных проверок: 3.
   2. Порог неуспешных проверок: 3.
   3. Интервал проверок: 10 секунд.
2. Проверьте, что балансировщик работает: в разные моменты приходят ответы от обоих экземпляров.

<a id="solution"></a>
### Решение

<a id="console"></a>
#### Консоль

1. Откройте EC2.
2. В левом меню выберите **Load balancing → Load balancers**.
3. Нажмите **Create load balancer**.
4. Выберите **Application Load Balancer**.
5. Введите имя балансировщика.
6. Выберите зоны доступности, в которых он будет работать.
7. Выберите группу безопасности.
8. В разделе **Listeners and routing** нажмите **Create target group** и выберите **Instances**:
   1. Укажите имя целевой группы.
   2. Порог успешных проверок: 3.
   3. Порог неуспешных проверок: 3.
   4. Интервал: 10 секунд.
   5. Нажмите **Next** и выберите два экземпляра.
   6. Нажмите **Create target group**.
9. Обновите список целевых групп и выберите созданную.
10. Нажмите **Create load balancer** и дождитесь завершения создания.
11. Скопируйте DNS-адрес балансировщика и откройте его в браузере. При обновлении страницы сообщения могут различаться в зависимости от экземпляра, которому направлен запрос.
