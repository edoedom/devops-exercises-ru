## Подсчёт символов

<a id="objectives"></a>
### Задание

[Условие](../count_chars.md).

<a id="solution"></a>
### Решение

[Исполняемый пример](scripts/count_chars.sh) — единственный источник кода; именно его запускают автоматические тесты.

Читает stdin циклом `while` до пустой строки или EOF. Для каждой непустой строки выводит `${#line}`. `IFS= read -r` сохраняет пробелы и обратные косые черты; последняя строка без перевода строки тоже обрабатывается. В UTF-8 locale считается число символов, а не байтов и не визуальных графем: `е` с отдельным комбинируемым знаком занимает два символа. NUL не поддерживается строками Bash. Аргументы не требуются.

Запуск из корня репозитория:

```bash
bash topics/shell/solutions/scripts/count_chars.sh
```

Ошибки входных данных выводятся в stderr с кодом 2. Нужны Bash 4.4+ и GNU/Linux; общие требования описаны в [разделе Bash](../README.md).
