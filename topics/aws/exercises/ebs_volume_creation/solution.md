## AWS EC2: создание тома EBS

<a id="requirements"></a>
### Требования

Один экземпляр EC2, который можно удалить.

<a id="objectives"></a>
### Задание

1. Создайте том в той же зоне доступности, что и экземпляр:
   1. Тип тома: gp2.
   2. Размер: 4 ГиБ.
2. Подключите созданный том к экземпляру EC2.
3. Удалите экземпляр. Что произошло с подключёнными к нему томами EBS?

<a id="solution"></a>
### Решение

1. Откройте EC2.
2. В разделе **Elastic Block Store** выберите **Volumes**.
3. Нажмите **Create Volume**.
4. Укажите параметры:
   1. Тип: gp2.
   2. Размер: 4 ГиБ.
   3. Та же зона доступности, что и у экземпляра.
5. Нажмите **Create volume**.
6. В контекстном меню созданного тома выберите **Attach volume**, укажите экземпляр EC2 и нажмите **Attach**.
7. Завершите существование экземпляра (terminate).
8. Исходный том EBS, созданный при запуске экземпляра, удалится, если для него включён параметр **Delete on termination**. Дополнительный том из этого упражнения в описанном сценарии сохранится.

Примечание: после упражнения не забудьте удалить созданный том EBS.
