## AWS VPC: подсети

<a id="requirements"></a>
### Требования

1. Одна недавно созданная VPC.
2. Регион с более чем двумя зонами доступности.

<a id="objectives"></a>
### Задание

1. Создайте первую подсеть в VPC:
   1. CIDR: 10.0.0.0/24.
   2. Имя: NewSubnet1.
2. Создайте вторую подсеть:
   1. CIDR: 10.0.1.0/24.
   2. Имя: NewSubnet2.
   3. Другая зона доступности.
3. Создайте третью подсеть:
   1. CIDR: 10.0.2.0/24.
   2. Имя: NewSubnet3.
   3. Зона доступности, отличная от зон первых двух подсетей.

<a id="solution"></a>
## Решение

<a id="console"></a>
### Консоль

1. В разделе **Virtual Private Cloud** выберите **Subnets**.
2. В левом меню отфильтруйте список по своей VPC, чтобы не видеть подсети остальных VPC.
3. Нажмите **Create subnet**.
4. Выберите свою VPC.
5. Имя первой подсети: NewSubnet1.
6. Выберите зону доступности.
7. CIDR: 10.0.0.0/24.
8. Нажмите **Add new subnet**.
9. Имя второй подсети: NewSubnet2.
10. Выберите другую зону доступности.
11. CIDR: 10.0.1.0/24.
12. Нажмите **Add new subnet**.
13. Имя третьей подсети: NewSubnet3.
14. Выберите третью зону доступности.
15. CIDR: 10.0.2.0/24.
