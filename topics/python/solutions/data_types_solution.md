## Типы данных: решение

1. a = [1, 2, 3, 4, 5] -> list (список)
2. b = "Hello, is it me you looking for?" -> string (строка)
3. e = 100 -> int (целое число)
4. f = '100' -> string (строка)
5. i = 0.100 -> float (число с плавающей точкой)
6. i = True -> bool (логическое значение)
